# SCUMM for Parrot Cart

Plays SCUMM adventure games from /SCUMM, with saves.

## Install

1. Copy `SCUMM-0.2.7.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your .lfl .000 files in `/SCUMM`.
3. On the cart: Home, Plugins, SCUMM, then A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| `.lfl` `.000` | `/SCUMM` | Nothing extra |
