# Pad Test for Parrot Cart

Shows a USB pad's buttons and sticks on the TV as they move.

## Install

1. Copy `PADTEST.CVP` to `/PLUGINS` on the cart's microSD card.
2. On the cart: Home, Plugins, Pad Test, then A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files: it is an app | None | USB host |
