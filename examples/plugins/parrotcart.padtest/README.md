# Pad Test for Parrot Cart

The Pad Test plugin is a tester for USB gamepads.

## Install

1. Copy `PADTEST.CVP` to `/PLUGINS` on the cart's microSD card.
2. On the cart, press B for Home, open Plugins, pick Pad Test and press A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files, since it's an app | None | USB host |
