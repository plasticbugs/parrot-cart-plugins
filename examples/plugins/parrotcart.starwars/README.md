# Star Wars for Parrot Cart

The Star Wars plugin is an emulator for the vector-based arcade game.

## Install

1. Copy `STARWARS.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your own Star Wars ROM files (MAME's `starwars` set) in `/STARWARS`, loose or zipped, or as `/STARWARS.ZIP`.
3. On the cart, press B for Home, open Plugins, pick Star Wars and press A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files, since it's an app | `/STARWARS` | USB host |
