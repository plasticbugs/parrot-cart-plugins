# Star Wars for Parrot Cart

Plays the 1983 Star Wars arcade game from your own ROM files, with a USB pad as the yoke.

## Install

1. Copy `STARWARS.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your own Star Wars ROM files (MAME's `starwars` set) in `/STARWARS`, loose or zipped, or as `/STARWARS.ZIP`.
3. On the cart: Home, Plugins, Star Wars, then A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files: it is an app | `/STARWARS` | USB host |
