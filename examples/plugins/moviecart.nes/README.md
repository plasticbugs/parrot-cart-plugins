# NES for Parrot Cart

Plays NES games from /NES, with USB pads.

## Install

1. Copy `NES-0.4.7.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your .nes files in `/NES`.
3. On the cart: Home, Plugins, NES, then A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| `.nes` | `/NES` | USB host, PSRAM |
