# SCUMM for Parrot Cart

The SCUMM plugin is an engine for classic point-and-click adventure games.

## Install

1. Copy `SCUMM.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your .lfl .000 files in `/SCUMM`.
3. On the cart, press B for Home, open Plugins, pick SCUMM and press A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| `.lfl` `.000` | `/SCUMM` | Nothing extra |
