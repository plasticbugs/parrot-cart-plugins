PSG SYNTH FOR PARROT CART

The PSG Synth plugin is a
synth for USB MIDI keyboards.

INSTALL

1. Copy PSGSYNTH.CVP to
   /PLUGINS on the cart's
   microSD card.
2. On the cart, press B for
   Home, open Plugins, pick
   PSG Synth and press A.

WHAT IT NEEDS

Opens: No files, since it's
  an app
Folder: None
Uses: USB host

CREDITS

It was written for Parrot Cart
with the SDK.

SOURCE

This is an example. The source
code isn't public yet.
