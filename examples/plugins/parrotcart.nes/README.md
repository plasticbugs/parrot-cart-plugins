# NES for Parrot Cart

The NES plugin is an emulator for Nintendo's 8-bit console.

## Install

1. Copy `NES.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your .nes files in `/NES`.
3. On the cart, press B for Home, open Plugins, pick NES and press A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| `.nes` | `/NES` | USB host, PSRAM |
