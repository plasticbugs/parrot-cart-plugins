GAME BOY FOR PARROT CART

Plays Game Boy games from /GB,
with saves and USB pads.

INSTALL

1. Copy GB-0.1.2.CVP to
   /PLUGINS on the cart's
   microSD card.
2. Put your .gb .gbc files in
   /gb.
3. On the cart: Home, Plugins,
   Game Boy, then A.

WHAT IT NEEDS

Opens: .gb .gbc
Folder: /gb
Uses: USB host, PSRAM
