PSG SYNTH FOR PARROT CART

Plays the console's sound chip
from a USB MIDI keyboard.

INSTALL

1. Copy PSGSYNTH-1.0.0.CVP to
   /PLUGINS on the cart's
   microSD card.
2. On the cart: Home, Plugins,
   PSG Synth, then A.

WHAT IT NEEDS

Opens: No files: it is an
  app
Folder: None
Uses: USB host

CREDITS

Written for Parrot Cart with
its SDK.
