# Empire Strikes Back for Parrot Cart

The Empire Strikes Back plugin is an emulator for the vector-based arcade sequel.

## Install

1. Copy `ESB.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your own Empire Strikes Back ROM files (MAME's `esb` set) in `/ESB`, loose or zipped, or as `/ESB.ZIP`.
3. On the cart, press B for Home, open Plugins, pick Empire Strikes Back and press A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files, since it's an app | `/ESB` | USB host |
