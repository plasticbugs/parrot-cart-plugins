# Empire Strikes Back for Parrot Cart

Plays the 1985 Empire Strikes Back arcade game from your own ROM files, with a USB pad.

## Install

1. Copy `ESB.CVP` to `/PLUGINS` on the cart's microSD card.
2. Put your own Empire Strikes Back ROM files (MAME's `esb` set) in `/ESB`, loose or zipped, or as `/ESB.ZIP`.
3. On the cart: Home, Plugins, Empire Strikes Back, then A.

## What it needs

| Opens | Folder | Uses |
|---|---|---|
| No files: it is an app | `/ESB` | USB host |
