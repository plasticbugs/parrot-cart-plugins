# ColecoVision

This plugin plays ColecoVision games from the SD card. It's built into the Parrot Cart, so there's nothing to install.

## Setup

Put your `.rom` and `.col` files anywhere on the card. Pick one in the menu to play it.

- Plain cartridges from 8K to 32K work.
- MegaCart games up to 1 MB work too, such as Mappy.
- Super Game Module games work when a Super Game Module is plugged into the console.

A few of the biggest MegaCart games don't fit in the cart's memory. The menu says "Too big for the cart's RAM" when that happens.

## Controls

Play with the ColecoVision controllers, the same as with any cartridge. USB pads don't work with ColecoVision games.

Press RESET on the console to go back to the menu. The menu comes back with the game you played selected.
